# Print Agent

Программа для складских ПК: живёт в трее, запускается вместе с Windows и сама обновляется с GitHub Releases.
Печать заданий с сайта появится в следующих версиях.

## Установка на ПК
1. Скачать `PrintAgent.exe` из последнего релиза.
2. Запустить. Программа скопирует себя в `%LOCALAPPDATA%\PrintAgent`, включит автозапуск и появится в трее.
3. Скачанный файл можно удалить.

## Выпуск новой версии
```
git tag v0.1.1
git push origin v0.1.1
```
GitHub Actions соберёт exe и выложит релиз. ПК обновятся в течение часа (или сразу через «Проверить обновления» в меню трея).

Номер версии берётся из тега, в коде его менять не нужно.

## Настройка
`agent/config.py` — `GITHUB_REPO` (владелец/репозиторий с релизами), интервал проверки обновлений.

## Запуск при разработке
```
pip install -r requirements.txt
python main.py
```
В этом режиме программа не устанавливается и не обновляется, только показывает значок в трее.
Лог: `%LOCALAPPDATA%\PrintAgent\agent.log`.
