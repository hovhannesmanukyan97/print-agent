# Print Agent

Программа для складских ПК: живёт в трее, запускается вместе с Windows, сама обновляется с GitHub Releases
и печатает задания с сайта (стикеры WB, этикетки Ozon...) на выбранные принтеры без окна выбора принтера.
Серверная часть - `controllers/print_agent.php` в проекте 15min.store.

## Установка на ПК
1. Скачать `PrintAgent.exe` из последнего релиза (или «Склад → Рабочие места печати → Скачать программу»).
2. Запустить. Программа скопирует себя в `%LOCALAPPDATA%\PrintAgent`, включит автозапуск и появится в трее.
3. Программа откроет браузер на странице подключения: там (под своим логином) выбрать склад и нажать «Подключить».
   Этот браузер запоминает рабочее место - сканы в нём печатают на этом ПК.
4. Откроется окно «Настройки»: выбрать принтер для каждого формата, проверить «Пробной печатью», сохранить.

Меню в трее: статус, «Настройки», «Привязать браузер» (если почистили cookie или сменили браузер),
«Проверить обновления», автозапуск, папка программы, выход.

## Как работает
- Подключение: программа придумывает uid + секрет -> `api_register` -> браузер на `/print_agent/connect` ->
  `api_claim` каждые 3 сек, пока сайт не выдаст токен. Секрет и токен в `settings.json` зашифрованы (DPAPI).
- Печать: каждые 2 сек `api_poll` (заодно «я на связи» и выбранные принтеры) -> `api_file` -> печать -> `api_result`.
- PNG и PDF вписываются в печатную область принтера; размер этикетки задаётся в драйвере принтера.

## Выпуск новой версии
```
git tag v0.2.0
git push origin v0.2.0
```
GitHub Actions соберёт exe и выложит релиз. ПК обновятся в течение часа (или сразу через «Проверить обновления»).
Обновление ждёт, пока допечатается текущее задание. Номер версии берётся из тега.

## Настройка
`agent/config.py` - `GITHUB_REPO`, `SERVER_URL`, интервалы. Для разработки в `settings.json`
можно указать `"server_url": "https://darkstore.loc"` (для `*.loc` сертификат не проверяется).

## Запуск при разработке
```
pip install -r requirements.txt
python main.py
```
В этом режиме программа не устанавливается и не обновляется. Лог: `%LOCALAPPDATA%\PrintAgent\agent.log`.
